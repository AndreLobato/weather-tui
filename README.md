
# Weather-TUI

A Rust TUI for checking the weather.

Features:

- Map Layers
- Settings
  - Data Source selector
  - Units
  - Keyboard Shortcuts
  - UI components
- Location selector
  - Summary
  - Time-series graphs and values
- Climate
- Forecast
- Topography
- Ocean
  - Bathymetry
  - Tide
  - Currents
  - Sea Surface Temperature
  - Storm surge
  - Waves
    - Height
    - Peak Period
    - Mean Peak Direction
- Atmosphere
  - Winds
    - Surface
    - Multi-level
  - Cloud-cover
  - Precipitation (Rain, Hail, Snow)
  - Lightning
  - Rain Radar
- Alerts
